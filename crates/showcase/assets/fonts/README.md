# Bundled raster font

`Roboto-Regular.ttf` is used only by the deterministic SVG-to-PNG renderer.
It is pinned to Google Fonts commit
`376ff5c1ab3952ec7d324a2222f1018a09b2a437` and distributed under the adjacent
Apache License 2.0.

Source:
<https://github.com/google/fonts/tree/376ff5c1ab3952ec7d324a2222f1018a09b2a437/apache/roboto>
