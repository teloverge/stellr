# stellr M1 — "The Chart" Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A single Rust binary (`stellr serve`) that syncs a GitHub repo's issues and serves an interactive star-map — blockers as edges, closed issues as resolved stars, frontier highlighted — viewable in any browser or IDE pane, on Windows 11.

**Architecture:** Cargo workspace with pure-domain `core` (issue graph + status derivation, no I/O), `github` provider (gh-token auth, GraphQL sync, textual `Blocked by #N` fallback, disk snapshot cache), `server` (axum: REST + JSON control websocket pushing whole-model snapshots, embedded SPA), and `app` (clap CLI, serve mode only in M1). The Svelte 5 SPA ports chartr's canvas star-map renderer verbatim behind an adapter seam. Spec: `docs/specs/2026-07-29-stellr-port-design.md`. Reference implementation: `D:\dev\chartr` (Go); verbatim-port assets staged in `reference/`.

**Tech Stack:** Rust (edition 2024), tokio, axum 0.8, octocrab, wiremock, rust-embed, clap, serde, directories, chrono; Svelte 5 (runes) + Vite + TypeScript + Tailwind v4, vitest + jsdom, marked + dompurify; no SvelteKit, no CDN assets.

## Global Constraints

- **Windows 11 is first-class:** every command in this plan must work in PowerShell on Windows; paths in code use `PathBuf`, never hard-coded separators. CI runs the full suite on `windows-latest`.
- **Build order:** `npm --prefix web run build` must run before any cargo command that compiles `stellr-app` (rust-embed needs `web/dist/`). Backend-only iteration: `cargo test -p stellr-core -p stellr-github -p stellr-server`.
- **Crate names:** `stellr-core`, `stellr-github`, `stellr-server`, `stellr-app` (binary name `stellr`), in `crates/core`, `crates/github`, `crates/server`, `crates/app`.
- **Attribution (spec §9):** every file ported substantially intact from chartr carries a header comment: `// Derived from chartr (https://github.com/rengwu/chartr), MIT, Copyright (c) 2026 John Goh.` `LICENSE-chartr` already exists at repo root — do not remove it.
- **No CDN, no runtime fetch of assets:** fonts, icons, and libraries are bundled. The only network calls at runtime are to `api.github.com`.
- **Frontend colour discipline (spec §5):** every colour is a CSS custom-property token defined in `web/src/app.css`; no raw hex/rgb in components. Star-map status hues live in the renderer's `theme.ts` (exempt data-viz colours) fed through the adapter seam.
- **Writes to GitHub: none in M1.** M1 is read-only; claim/release lands in M3.
- **Commits:** small, per task step as marked; message style `feat:`/`fix:`/`test:`/`docs:`/`chore:`; end commit messages with the Co-Authored-By trailer used in this repo's history.
- **Deviation log (approved during planning):** GitHub **device flow** auth is deferred to M2 (it needs UI surface); M1 requires `gh` CLI login or `GITHUB_TOKEN`. Poll interval is a fixed 30 s in M1; focus-based backoff arrives with the Tauri shell in M2. Milestone cluster *visuals*, search/filter, minimap are M4; milestone data still flows through the model now.

**Interfaces:**
- Produces: `pub fn derive(issues: &[RawIssue]) -> Vec<Star>` — stars sorted by `number` ascending. Rules (spec §3 table, in precedence order per issue):
  1. `ClosedNotPlanned` → `OutOfScope`
  2. `Closed` → `Resolved`
  3. open + any assignee → `Claimed`
  4. open + any blocker whose state is `Open` → `Blocked`
  5. otherwise → `Frontier`
  - Blocker refs to numbers **not in the input set** are dropped from `blocked_by` (cross-repo/PR refs can't render as edges). Self-references dropped. Duplicates deduped, `blocked_by` sorted ascending.
  - A blocker closed for *either* reason no longer blocks.

```rust
use crate::model::{IssueState, RawIssue, Star, Status};
use std::collections::BTreeMap;

pub fn derive(issues: &[RawIssue]) -> Vec<Star> {
    let states: BTreeMap<u64, IssueState> = issues.iter().map(|i| (i.number, i.state)).collect();
    let mut stars: Vec<Star> = issues
        .iter()
        .map(|i| {
            let mut blocked_by: Vec<u64> = i
                .blocked_by
                .iter()
                .copied()
                .filter(|n| *n != i.number && states.contains_key(n))
                .collect();
            blocked_by.sort_unstable();
            blocked_by.dedup();
            let any_open_blocker = blocked_by.iter().any(|n| states[n] == IssueState::Open);
            let status = match i.state {
                IssueState::ClosedNotPlanned => Status::OutOfScope,
                IssueState::Closed => Status::Resolved,
                IssueState::Open if !i.assignees.is_empty() => Status::Claimed,
                IssueState::Open if any_open_blocker => Status::Blocked,
                IssueState::Open => Status::Frontier,
            };
            Star {
                number: i.number, title: i.title.clone(), status, blocked_by,
                milestone: i.milestone.clone(), labels: i.labels.clone(),
                assignees: i.assignees.clone(), url: i.url.clone(), body: i.body.clone(),
            }
        })
        .collect();
    stars.sort_unstable_by_key(|s| s.number);
    stars
}
```

**Interfaces:**
- Produces: `pub struct TextRefs { pub blocked_by: Vec<u64>, pub blocks: Vec<u64> }`; `pub fn scan(body: &str) -> TextRefs`.
- Rules: a line whose text (after stripping leading whitespace, `-`/`*` list markers, and `> ` quote markers) starts case-insensitively with `blocked by` contributes every `#N` on that line to `blocked_by`; a line starting with `blocks` contributes to `blocks`. ```rust
#[derive(Debug, Default, PartialEq)]
pub struct TextRefs {
    pub blocked_by: Vec<u64>,
    pub blocks: Vec<u64>,
}

pub fn scan(body: &str) -> TextRefs {
    let mut refs = TextRefs::default();
    let mut in_fence = false;
    for raw in body.lines() {
        let trimmed = raw.trim_start();
        if trimmed.starts_with("```") || trimmed.starts_with("~~~") {
            in_fence = !in_fence;
            continue;
        }
        if in_fence {
            continue;
        }
        let stripped = trimmed
            .trim_start_matches(['-', '*', '>'])
            .trim_start();
        let lower = stripped.to_ascii_lowercase();
        let bucket = if lower.starts_with("blocked by") {
            &mut refs.blocked_by
        } else if lower.starts_with("blocks") {
            &mut refs.blocks
        } else {
            continue;
        };
        let mut chars = stripped.char_indices().peekable();
        while let Some((i, c)) = chars.next() {
            if c == '#' {
                let digits: String = stripped[i + 1..].chars().take_while(|c| c.is_ascii_digit()).collect();
                if let Ok(n) = digits.parse::<u64>() {
                    bucket.push(n);
                }
            }
        }
    }
    refs.blocked_by.sort_unstable();
    refs.blocked_by.dedup();
    refs.blocks.sort_unstable();
    refs.blocks.dedup();
    refs
}
```

use thiserror::Error;

#[derive(Debug, Error)]
pub enum AuthError {
    #[error("no GitHub token: {0}. Run `gh auth login` or set GITHUB_TOKEN.")]
    NotFound(String),
}

pub fn resolve_token() -> Result<String, AuthError> {
    let env = std::env::var("GITHUB_TOKEN").ok();
    let gh = std::process::Command::new("gh")
        .args(["auth", "token"])
        .output()
        .ok()
        .filter(|o| o.status.success())
        .map(|o| String::from_utf8_lossy(&o.stdout).into_owned());
    resolve_with(env, gh)
}

fn resolve_with(env: Option<String>, gh_output: Option<String>) -> Result<String, AuthError> {
    if let Some(t) = env.filter(|t| !t.trim().is_empty()) {
        return Ok(t);
    }
    if let Some(t) = gh_output.map(|t| t.trim().to_string()).filter(|t| !t.is_empty()) {
        return Ok(t);
    }
    Err(AuthError::NotFound("neither GITHUB_TOKEN nor `gh auth token` yielded one".into()))
}
```

async fn control_ws(State(s): State<Arc<AppState>>, ws: axum::extract::ws::WebSocketUpgrade) -> impl IntoResponse {
    ws.on_upgrade(move |socket| control_loop(socket, s))
}

async fn control_loop(mut socket: axum::extract::ws::WebSocket, s: Arc<AppState>) {
    let mut rx = s.hub.subscribe();
    let snapshot = serde_json::to_string(&*rx.borrow_and_update()).expect("model serializes");
    if socket.send(axum::extract::ws::Message::Text(snapshot.into())).await.is_err() {
        return;
    }
    loop {
        tokio::select! {
            changed = rx.changed() => {
                if changed.is_err() { return; }
                let snap = serde_json::to_string(&*rx.borrow_and_update()).expect("model serializes");
                if socket.send(axum::extract::ws::Message::Text(snap.into())).await.is_err() { return; }
            }
            msg = socket.recv() => {
                match msg { None | Some(Err(_)) => return, Some(Ok(_)) => {} } // ignore client frames in M1
            }
        }
    }
}
